## 🎮 Games

### 1. Tic-Tac-Toe
**Folder:** `tic-tac-toe/` 

A classic two-player Tic-Tac-Toe game built with vanilla HTML, CSS, and JavaScript.

| File | Description |
|------|-------------|
| `TIC TAC TOE.html` | Game layout and board UI |
| `STYLE.css` | Board and cell styling |
| `app.js` | Game logic — win detection, turn switching, reset |

**Tech:** `HTML` `CSS` `JavaScript`

---

### 2. Simon Says Game
**Folder:** `simon-says-game/`

A memory-based sequence game where the player must repeat an ever-growing pattern of colored button flashes.

| File | Description |
|------|-------------|
| `index.html` | Game board layout |
| `style.css` | Color button styling and animations |
| `app.js` | Sequence generation, input validation, level progression |

**Tech:** `HTML` `CSS` `JavaScript`
